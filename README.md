# Concevez-un-r-seau-local-et-organisez-son-d-ploiement
Conception du réseau du projet : réalisation d’un schéma physique (équipements, capacité des switches) et logique (VLAN, sous-réseaux, masques), définition du plan d’adressage (DHCP et IP fixes), puis planification via un diagramme de Gantt. Outils : draw.io et Excel, en respectant les bonnes pratiques ANSSI.
